# petjabel.github.io

Web pages for apps by Petibel, published with GitHub Pages at https://petjabel.github.io/.

- `/framazing/` – Framazing (Рамкастично): `privacy/` and `support/` (English), each with `bg/` (Bulgarian)
- `/app-ads.txt` – AdMob's authorised sellers file; it must stay at the site root
- `/style.css` – shared styles

Plain HTML and CSS, no build step. The app's source code lives in a separate private repository.
